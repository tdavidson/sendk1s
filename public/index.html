Prepare and Send K-1s

Send K-1 tax documents to partners using Gmail or SendGrid, with optional redaction and password-protected encryption.

Overview

▼

For fund managers and tax preparers. Typical workflow:

  1. Prepare K-1 PDFs: redact (optional) and encrypt (optional)
  2. Create your email template Write the default email to send to partners
  3. Prepare your email list Create a CSV file with the email addresses of your partners and contacts
  4. Test matching to verify PDF filenames match your limited partners before sending
  5. Send K-1s via Gmail or SendGrid

Prepare modes:

  • Redact only — Redacts SSN/TIN on the page
  • Encrypt only — Encrypts PDFs with password (e.g. after redaction)
  • Both — Redact, then encrypt

Keep confidential documents in ignore/. Put K-1 PDFs in a subfolder (e.g. ignore/2025_fund_name/original/).

2. Test matching

Verify each LP in your CSV has exactly one matching PDF (use the _protected or _redacted_protected folder).

3. Test send

Send one LP's K-1 to a test address to review before full send.

4. Full send

Send all K-1s via Gmail. Requires credentials.json and token.json.

Confidential files in ignore/ are gitignored. Never commit credentials.json, token.json, or .env.
