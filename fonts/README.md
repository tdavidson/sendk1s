# Font for redaction overlay

The redaction script draws the masked SSN/TIN (e.g. `**-***6570`) in **Courier Prime** to match the filled fields on the K-1 form. The font is embedded for consistent display across viewers (Gmail, Preview, Adobe, etc.).

**Font:** `CourierPrime-Regular.ttf` (Google Fonts) is included. If the font file is missing, the script falls back to the standard PDF Courier reference.
